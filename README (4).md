# Customer Segmentation (Unsupervised Learning)

## Overview
This project applies PCA and K-Means clustering to segment customers.

## Steps
- Data preprocessing
- PCA dimensionality reduction
- Elbow method
- Silhouette score
- Final clustering

## Tech Stack
- Python
- Scikit-learn
- Pandas
- Matplotlib

## How to Run
1. Add your dataset as `data.csv`
2. Run the notebook
